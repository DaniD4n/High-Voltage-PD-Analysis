# Partial Discharge Statistical Analysis

## Main Objective

Develop statistical models capable of characterizing Partial Discharge measurements and supporting the generation of realistic synthetic datasets for Machine Learning applications.

## Overview

This repository contains tools for the statistical analysis and preprocessing of Partial Discharge (PD) measurements.

The project is being developed as part of the activities of the High Voltage Laboratory (LAT), with the long-term objective of supporting the generation of realistic synthetic PD datasets for Machine Learning applications.

Current work focuses on:

* Measurement data exploration
* Noise filtering techniques
* Statistical characterization of PD events
* Density estimation methods
* Gaussian Mixture Models (GMM)
* Feature extraction and validation

The methodologies developed here will serve as a foundation for future synthetic data generation and AI training pipelines.

---

## Research Context

Partial Discharge measurements are commonly used for the diagnosis and monitoring of high-voltage insulation systems. However, obtaining large and diverse datasets can be challenging.

This project investigates statistical approaches to characterize real PD measurements and reproduce their behavior through synthetic data generation techniques.
